# Rising Tigers Initiative

The public resource hub for the Rising Tigers Initiative — activism, contributor artifacts, and the sourced claim library backing all of it.

**Live at:** [risingtigers.tahreemkarim.xyz](https://risingtigers.tahreemkarim.xyz)

## Structure

| Path | What it holds |
|---|---|
| `/` | Hub — links to everything below, plus out to [portfolio](https://portfolio.tahreemkarim.xyz), [garden](https://garden.tahreemkarim.xyz), and [free resources](https://tahreemkarim.xyz) |
| `/activism` | The flagship artifact — Sudan/Congo/Palestine displacement, Bengal tiger/deforestation/pollution |
| `/artifacts/<slug>/` | Every other piece — articles, dashboards, projects, mine or a contributor's |
| `/library/` | The sourced claim collection everything above cites into — forkable, correctable, meant to grow into its own resource over time |
| `/docs/` | How this repo is organized and how to contribute |

## The distinction that shapes everything here

If it argues something, it's an artifact. If it substantiates an argument, it's the library. Full reasoning in [`docs/explanation/documentation-standards.md`](docs/explanation/documentation-standards.md).

# resources

A public, forkable collection of the sources, datasets and tools behind my work.

Maintained by [Tahreem Karim](https://portfolio.tahreemkarim.xyz). Everything here is free and
linked to a primary source. Corrections welcome as issues or PRs.

## Why this exists

Because "source?" should have a one-click answer, and because a link in a footer rots quietly while
a file in a repo rots loudly — in public, where someone can fix it.

## What's here

| Folder | Contents |
|---|---|
| `activism/` | Every figure behind the [Six fires](https://portfolio.tahreemkarim.xyz/activism) page, with provenance, caveats and check dates. |
| `bio-viz/` | Visualisation tools for biology — what each one is actually for, what it costs, and the free alternative. |
| `datasets/` | Open biological and environmental datasets worth knowing, with access notes. |
| `figures/` | Canonical figures worth studying, and why they work. |

## What's *not* here

- **Books I've read** → those live in [the library](https://garden.tahreemkarim.xyz/library), with notes. Personal, not reference.
- **Half-formed thinking** → [the garden](https://garden.tahreemkarim.xyz). Nothing there is finished on purpose.
- **My own papers and code** → [free resources](https://www.tahreemkarim.xyz), downloadable, no email required.

The rule: if it's *mine and finished*, it goes on the portfolio. If it's *mine and unfinished*, the
garden. If it's *someone else's and worth pointing at*, it goes here.

## Contributing

Open an issue if a link is dead, a figure is stale, or something obvious is missing. If you're
adding an entry, include the primary source and the date you checked it — an entry without a
check date is worse than no entry.
